## Launching
### Database
1. Create a MongoDB Atlas (https://cloud.mongodb.com/) account and set up a new cluster.
2. Create a new database and collection for flashcards.
3. Get the connection string for your MongoDB Atlas cluster.
4. Add your connection string to file named .env in the backend directory as MONGODB_URI=your_connection_string
5. Add port number to .env file as PORT=5000

### Backend
1. Navigate to the backend directory in your terminal.
2. Install dependencies by running npm install.
3. Run npm install in the backend directory to install dependencies.
4. Run npm run dev in the backend directory to start the server.
5. The backend server should now be running on http://localhost:5000.
6. You can test the API endpoints using tools like Postman or cURL.

### Frontend
1. Navigate to the frontend directory in your terminal.
2. Install dependencies by running npm install.
3. Run npm run dev in the frontend directory to start the development server.
4. Open http://localhost:3000 in your web browser to view the application.
